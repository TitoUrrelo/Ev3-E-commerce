# AtacamaPro - Mockup interactivo (React + Vite)

    npm install
    npm run dev      # abre http://localhost:5173
    npm run build    # genera la carpeta dist/

Archivos clave: `src/data.js` (productos, perfiles y motor de recomendación híbrido), `src/App.jsx` (pantallas), `src/styles.css` (estilos).
